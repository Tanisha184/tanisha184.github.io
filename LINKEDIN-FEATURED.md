# LinkedIn Featured — what to use

## Standard practice

- **Article link:** Use the **post URL**, not the home page. LinkedIn shows `og:image` (1200×630) from that page.
- **Home link:** Uses `og-site.png` (branded card, no portrait).
- **Full control:** Featured → **Media** → upload a PDF or image yourself (LinkedIn does not scrape).

## Refresh preview after OG changes

1. Wait for GitHub Pages to deploy (~2 min).
2. Open [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/) and inspect the URL.
3. Edit Featured → remove old link → add again with a clear **title** (use the article headline, not “Production write-ups”).

## Later: Oneiroi Systems

When posts move to oneiroi systems.com/blog, add the same `og:image` per post there and point Featured / company page to those URLs.
